# EvolveIR 2027

Website for **EvolveIR: Workshop on Evolving Information Retrieval and Recommendation Systems**, co-located with ECIR 2027 in Southampton, UK.

## Local preview

This is a static site with no build dependencies. Open `index.html` directly, or run `python -m http.server 8000` and visit `http://localhost:8000`.

## Publishing

In the repository settings, open **Pages**, select **Deploy from a branch**, and choose the root of the `main` branch.

Before the call opens, replace all “To be announced” labels and connect the submission button to the official submission portal.
